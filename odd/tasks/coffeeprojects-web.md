- **S23** — "Arréglame en el panel en la parte de proyecto poder poner URL y que en base a la URL coja la portada y todo lo de la web" + "lo quiero en el panel de coffee projects que hiciste en su momento". Acceptance (design decided by the agent, assumptions marked A):
  - In the panel, a project with a URL gets an «Importar desde la web» / «Import from website» action next to the URL field.
  - A team-only server endpoint fetches the public page and returns what it finds.
  - **Cover:** a screenshot of the home page (A: via the Microlink API, which takes the public URL only; optional `MICROLINK_API_KEY`). It falls back to `og:image` / `twitter:image`. The image is stored in Media with alt text.
  - **Fields:** title (`og:site_name`/`og:title`/`<title>`), summary (`og:description`/`meta description`), stack (detected technologies), year (current year) and the SEO title, description and image.
  - **Fill rule:** only empty fields are filled; the cover is replaced only on explicit choice (A). Values land in the form for review, and nothing is saved until the user saves.
  - **SSRF-safe:** http(s) only; private, loopback and link-local addresses refused on every redirect hop; time and size limits; image content-type checked.
  - **Errors:** clear messages in es/en.
